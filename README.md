# Quote Generator Pro

Professional quote generation for service businesses such as HVAC, plumbing, roofing, electrical, and construction.

## Status

🚧 In Development

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Git
- GitHub

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
